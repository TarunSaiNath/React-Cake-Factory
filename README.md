# 🎂 Cake Factory – React Mini Project

Cake Factory is a **simple, interactive React app** that lets users browse through different cakes and view detailed information such as **name, image, description, price, and rating**.  

It’s a small but neat project to practice **React state management, component-based UI, and basic styling**.

## ✨ Features

- 🎨 **Clean, card-based UI** for displaying cake details  
- 🖱️ **Clickable cake thumbnails** – click any cake image to view its details  
- ⭐ **Dynamic highlight** on the currently selected cake  
- 💰 Shows **price** and **rating** with styled badges  
- 📱 Simple, responsive-friendly layout using pure CSS  

---

## 🛠️ Tech Stack

- **React** (Functional Components + Hooks)
- **JavaScript (ES6+)**
- **CSS3**
